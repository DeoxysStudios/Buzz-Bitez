# **Buzz Bitez**
---
The **Buzz Bitez** project consists of a family of apps (iOS, Android, and a web app) designed to alert students of on-campus events where free food is available. This project is essentially an open-source “from the ground up” version of the **Free Food Alert** project that is used by other universities. The goal is to allow event coordinators to be able to send out alerts for any of their on-campus events, and for all students signed up on the app to receive an email, notification, or both whenever there’s an alert. 

Additionally, students will be able to view a page on the app containing a list of all existing alerts, along with details about the event, such as:
- The type of food available
- A summary of the event
- Estimate of amount of people who can be fed
- The time period when the food will be available
- Message Board under posts

Additionally, students will be able to message the event coordinators through the app (if the coordinator allows it for that event) to ask questions if necessary. Additionally, students will be able to “like” an event on the alert board if they intend to show up before the remaining food from the event becomes unavailable.
